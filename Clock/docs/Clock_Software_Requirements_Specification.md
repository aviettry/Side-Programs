# Software Requirements Specification

# Clock


# Requirements
| ID      | Name                   | Description                                                                  |
|---------|------------------------|------------------------------------------------------------------------------|
| CLK-01  | Time - Format          | The clock should display the current time in 12-hour format.                 |
| CLK-02  | Time - Cycle           | The clock should update the time every second.                               |
| CLK-03  | Background - Animation | The clock should have a button to toggle between 12-hour and 24-hour format. |
| CLK-04  | Background - Color     | The clock should have a button to set the time manually.                     |
| CLK-05  | Date - Format          | The clock should have a button to set the date manually.                     |
| CLK-06  | Date - Cycle           | The clock should have a button to set the alarm.                             |
| CLK-07  | Date - Day             | The clock should have a button to snooze the alarm.                          |
| CLK-08  | Admin - Test Mode      | The system shall provide a toggle for normal mode and test mode.             |
